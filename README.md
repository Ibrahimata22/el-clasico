# ملعب الكلاسيكو – نموذج أولي

## محتويات النسخة
- واجهة Flutter لتجربة حجز ملعب.
- اختيار يوم وموعد.
- تمييز بعض المواعيد كمحجوزة تجريبياً.
- إدخال بيانات العميل وتأكيد تجريبي.

## بناء APK من الهاتف عبر Codemagic
1. ارفع ملفات المشروع إلى مستودع GitHub مع الحفاظ على المجلد lib.
2. اربط المستودع بحساب Codemagic.
3. اختر Flutter، ثم شغّل workflow باسم El Clasico Android APK.
4. عند نجاح البناء، نزّل artifact باسم app-debug.apk وثبّته على هاتف Android.

ملف codemagic.yaml الموجود في جذر المشروع يجهز مجلدات Android/Web تلقائياً ثم يبني APK تجريبياً.

## تشغيل محلي (اختياري)
flutter pub get
flutter run

## تنبيه مهم
هذه نسخة تجريبية. الحجوزات لا تُحفظ على خادم ولا تتزامن بين الأجهزة، والمواعيد والأسعار افتراضية، ولا يوجد دفع إلكتروني حقيقي. لا تستخدمها لقبول حجوزات فعلية قبل إضافة backend، وقفل مواعيد ذري، والتحقق من إشعار الدفع من الخادم. ملف APK الناتج من workflow الحالي نسخة Debug للتجربة، وليس إصداراً منشوراً أو موقّعاً للتوزيع التجاري.
